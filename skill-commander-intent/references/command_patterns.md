# 常见命令模式参考

本文档按业务领域分类，提供典型的命令结构和参数识别模式。

## 飞书文档操作

### 创建文档
- **模式**：`[创建/生成/新建] + [类型] + [标题] + [关于/介绍/说明] + [主题]`
- **参数**：`type`（文档/表格/幻灯片）、`title`、`topic`、`template`
- **示例**："帮我创建一个关于项目周报的云文档" → type=文档, title=项目周报, topic=项目进展

### 编辑文档
- **模式**：`[修改/编辑/更新] + [文档] + [内容/格式/结构]`
- **参数**：`doc_id`、`section`、`action`（添加/删除/修改）、`new_content`
- **示例**："把第三段改成总结" → section=第三段, action=修改, new_content=总结

### 搜索文档
- **模式**：`[查找/搜索] + [文档/文件] + [关键词] + [时间范围]`
- **参数**：`keyword`、`owner`、`time_range`、`doc_type`
- **示例**："找一下上周张三发的项目文档" → keyword=项目, owner=张三, time_range=上周

## 日程与会议

### 创建日程
- **模式**：`[安排/预约/创建] + [会议/日程] + [时间] + [参与人] + [主题]`
- **参数**：`title`、`start_time`、`end_time`、`attendees`、`location`、`reminder`
- **示例**："明天下午3点和李四开项目评审会" → title=项目评审会, start_time=明天15:00, attendees=李四

### 查询日程
- **模式**：`[查看/查询] + [日程/会议/空闲时间] + [时间范围] + [人]`
- **参数**：`time_range`、`attendee`、`status`
- **示例**："这周有哪些会议" → time_range=本周

## 多维表格

### 数据操作
- **模式**：`[添加/更新/删除] + [记录/行/数据] + [到/在] + [表格名] + [字段=值]`
- **参数**：`table_id`、`record_id`、`fields`（键值对）
- **示例**："在任务表添加一条记录，负责人是王五，状态是进行中" → table=任务表, fields={负责人:王五, 状态:进行中}

### 数据统计
- **模式**：`[统计/汇总/计算] + [指标] + [按/根据] + [维度] + [时间范围]`
- **参数**：`metric`、`dimension`、`time_range`、`filter`
- **示例**："统计本月各项目的完成率" → metric=完成率, dimension=项目, time_range=本月

## 即时消息

### 发送消息
- **模式**：`[发送/通知/提醒] + [人/群] + [内容] + [时间]`
- **参数**：`recipient`、`content`、`send_time`（立即/定时）
- **示例**："通知项目群会议改到明天" → recipient=项目群, content=会议改到明天

### 搜索消息
- **模式**：`[查找/搜索] + [聊天记录/消息] + [关键词] + [群/人] + [时间]`
- **参数**：`keyword`、`chat_id`、`sender`、`time_range`
- **示例**："找一下昨天在群里讨论的需求" → keyword=需求, time_range=昨天

## 任务管理

### 创建任务
- **模式**：`[创建/分配/下发] + [任务/待办] + [给] + [负责人] + [截止时间]`
- **参数**：`title`、`assignee`、`due_date`、`priority`、`description`
- **示例**："给张三分配一个本周五前完成的设计任务" → assignee=张三, due_date=本周五, title=设计任务

### 查询任务
- **模式**：`[查看/查询] + [任务/待办] + [状态] + [负责人] + [时间]`
- **参数**：`status`、`assignee`、`time_range`、`project`
- **示例**："看看我未完成的任务" → status=未完成

## 通用分析请求

### 数据分析
- **模式**：`[分析/统计/汇总] + [数据/指标] + [来源] + [维度] + [输出格式]`
- **参数**：`data_source`、`metrics`、`dimensions`、`output_format`（图表/表格/文字）
- **示例**："分析这个表格中各地区的销售额，用柱状图展示" → dimensions=地区, metrics=销售额, output_format=柱状图

### 生成报告
- **模式**：`[生成/制作] + [报告/总结/周报] + [时间范围] + [主题] + [发给]`
- **参数**：`report_type`、`time_range`、`topic`、`recipient`、`format`
- **示例**："帮我生成本周的工作周报" → report_type=周报, time_range=本周
